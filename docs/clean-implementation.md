# Independent implementation policy

Engram Runtime is implemented from behavioral requirements and public standards.

## Rules

- Write all source code, tests, diagrams, interface copy, and sample data for this repository.
- Do not copy third-party workshop source, prose, screenshots, diagrams, datasets, or visual assets.
- Do not reproduce third-party internal component names in public product surfaces.
- Record external protocols and libraries accurately in dependency and interoperability documents.
- Prefer standards-based contracts so each dependency can be replaced.
- Require license metadata for distributed dependencies and generated distributions.

## Review gate

The repository includes a terminology check for product surfaces and a dependency
license report before a release tag is created.
